# 中国居民膳食指南（2022）核心要点

> 来源：中国营养学会《中国居民膳食指南（2022）》
> 适用对象：18-64岁一般健康人群，含大学生群体

## 八大核心准则

### 准则一：食物多样，合理搭配
- 每天摄入12种以上食物，每周25种以上（不含烹调油和调味品）
- 每天膳食应包含：谷薯类、蔬菜水果类、畜禽鱼蛋奶类、大豆和坚果类
- 谷薯类占主食的50%以上，全谷物和杂豆50-150g/d，薯类50-100g/d

### 准则二：吃动平衡，健康体重
- 每天身体活动6000步以上，每周至少5天中等强度身体活动≥150分钟
- BMI健康范围：18.5-23.9
- 大学生久坐时间每天不超过6小时

### 准则三：多吃蔬果、奶类、全谷、大豆
- 蔬菜≥300g/d（深色蔬菜占1/2以上）
- 水果200-350g/d
- 奶及奶制品300-500g/d
- 大豆及坚果25-35g/d

### 准则四：适量吃鱼、禽、蛋、瘦肉
- 每天动物性食物120-200g（每周鱼类2次、蛋类300-350g）
- 优先选择鱼和禽肉，少吃加工肉制品
- 畜肉（猪牛羊）40-75g/d，控制在适量范围

### 准则五：少盐少油，控糖限酒
- 食盐<5g/d（约2000mg钠）
- 烹调油25-30g/d
- 添加糖<25g/d（最好<15g）
- 不建议大学生饮酒

### 准则六：规律进餐，足量饮水
- 三餐定时定量，不漏餐、不暴饮
- 每天饮水1500-1700ml（男性）/1500ml（女性），首选白水
- 少喝含糖饮料

### 准则七：会烹会选，会看标签
- 学习阅读食品营养标签
- 外卖/餐厅就餐时注意"三减"（减盐减油减糖）

### 准则八：公筷分餐，杜绝浪费
- 使用公勺公筷
- 按需点餐，减少食物浪费

## 大学生膳食特别提示

1. **早餐必须吃**：不吃早餐影响认知功能和学习效率，早餐应含谷类+蛋白质食物+蔬果
2. **外卖高频人群注意钠超标**：外卖菜品普遍高油高盐，建议选择蒸/煮/炖类菜品
3. **夜宵控制**：晚22:00后不宜进食高热量食物，如需加餐选择牛奶/水果
4. **含糖饮料替代**：用白水、淡茶替代奶茶、碳酸饮料
5. **补充奶制品**：大学生钙摄入普遍不足，建议每天1杯牛奶或酸奶
6. **女生注意补铁**：女性每月生理期失血，应增加红肉、动物肝脏摄入频次

## 营养缺口评估维度（用于周/月分析）

| 评估维度 | 达标标准 | 不足判定 |
|---------|---------|---------|
| 食物多样性 | 每日≥12种 | 连续3天<8种 |
| 蔬菜摄入 | 每日≥300g | 日均<200g |
| 水果摄入 | 每日200-350g | 连续2天无水果 |
| 奶制品 | 每日300-500g | 每周<3次 |
| 鱼禽蛋肉 | 每日120-200g | 日均<100g或>250g |
| 全谷物 | 每日50-150g | 连续5天无全谷 |
| 钠摄入 | <2000mg/d | 日均>2500mg（高钠风险） |
| 添加糖 | <25g/d | 日均>50g（高糖风险） |
| 早餐 | 每日必吃 | 每周漏餐≥2次 |
| 夜宵 | 尽量避免 | 每周夜宵≥3次 |
